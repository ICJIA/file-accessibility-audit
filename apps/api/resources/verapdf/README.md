# Vendored veraPDF validation profile

`WCAG-2-2-Machine.xml` — veraPDF's **machine-testable** WCAG 2.2 validation
profile (107 rules; the human-judgment WCAG conditions are deliberately NOT in
this profile, matching this product's rule of never asserting failures a
machine cannot prove).

- **Source:** https://github.com/veraPDF/veraPDF-validation-profiles
  `PDF_UA/WCAG-2-2-Machine.xml`
- **Branch:** `rel/1.30` — version-matched to the veraPDF **1.30.x** engine
  installed on production (`/opt/verapdf`, probed 2026-08-26).
- **Commit:** `bc8e77300edd757f1eb0bc5a8d4c3b50380aa701`
- **Byte-identical to upstream** — do not edit this file; to update it, fetch
  the matching `rel/<engine minor>` branch when the server's engine is
  upgraded, and record the new commit here.
- **Verified on the production engine 2026-08-26:** `verapdf --profile
  WCAG-2-2-Machine.xml --format json <pdf>` exits 0/1 with the standard
  `validationResult` JSON (profileName "WCAG 2.2 machine validation profile"),
  ~5 s wall with a cold JVM — inside `REMEDIATION.VERAPDF_AUDIT_TIMEOUT_MS`.

Used by `apps/api/src/services/veraPdfBuffer.ts` to run the WCAG machine
check alongside the PDF/UA check on every PDF audit (kill switch:
`VERAPDF_WCAG_ENABLED=false`).
